————游戏足控主题，注意！

游戏只在github的该账号下发布，当心魔改版上传你的key与cookie
——————————————————
需要你更改的内容:           
1，deepseek的key，用于实时对话输出与控制速度        
2，Pixiv网站你的登陆cookie          
   ——你的key与cookie均只保存在本地，不会上传（用于方便下次使用）          
   ——Pixiv网站用于抓取过滤并显示图片     
                            
Pixiv官网:Pixiv.net
——————————————————  
右上角绿色按钮点击后有游戏全状态显示          
接入deepseek的api，实时对话，非传统文游，有剧情引导              
抓取Pixiv图片库，输入你的登陆cookie后可显示+18图片                  
图片预缓存12张，图片池固定100张以上，若不足则重复抓取50页中随机页码                     
可手动换图，支持附加词条搜索                
固定回复与ai推荐回复按钮，自定义回复             
节拍器299bmp~600bmp高节奏                 
——————————————————
抓取cookie教程:                 
电脑端:登陆Pixiv                     
      安装拓展程序Cookie-Editor或其他类似拓展          
      进入.pixiv.net项               
      复制PHPSESSID这一项的32位cookie(注意不要泄露)                
安卓等端:                  
      登陆Pixiv
      下载支持安装拓展的浏览器，推荐Kiwi Browser             
      其余步骤与电脑端一致
——————————————————
运行步骤:                  
   下载或复制dsgm_V2.py文件并运行python3 dsgm_V2.py（需要python3）              
   运行后弹出网址与cookie情况            
   浏览器打开http://127.0.0.1:4884        
   打开后等待自检             
   输入deepseek的key（模型锁定为flash）    
   输入Pixiv的32位cookie       
      ————需要外网才可访问Pixiv（推荐海鸥极速版，无限流量，签到广告后500MB以上高速流量）    
      ————不输入cookie同样可以进行游戏，但输入后可显示+18图片          
      ————若你输入了cookie图片库还是0，则说明你需要登陆Pixiv并在过滤设置里打开相关选项
